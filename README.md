# A Hug for the Little One

In a soft, golden world where the light is warm and gentle, a baby red panda wraps its paws around a tiny sleeping yellow duckling, holding it close in a quiet, tender embrace. The panda wears a delicate white daisy crown and a cozy mint-green knitted scarf, while a few pink petals drift slowly down around them, as if the world itself is pausing to admire this small, perfect moment of love and safety.

## What Each Part Means

- **The white daisy crown** — a simple, natural symbol of purity and care.
- **The mint-green knitted scarf** — warmth and comfort, like a handmade gift.
- **The warm golden bokeh background** — a soft, cozy world where nothing can go wrong.
- **The falling pink petals** — a gentle reminder that kindness blooms everywhere.

## How to Run

This is a Python script that uses only the standard library. It finds the picture (`entry.png`) in the folder next to it and writes a byte-for-byte identical copy to the output folder. You can choose the output folder with the `MAKEFUN_OUTPUT_DIR` environment variable; if it is not set, the program writes to `/output`.
